## Purpose

设置弹窗外观壳：按原型绘制 5 分类设置界面（通用/消息/发送/连接/日志与导出），所有设置项值本地存储但不驱动真实功能行为。

## ADDED Requirements

### Requirement: 设置弹窗展示
系统 SHALL 在点击设置入口时打开设置弹窗，包含左侧分类栏（5 分类）与右侧设置项面板，并支持打开/取消/保存/恢复默认。

#### Scenario: 打开设置弹窗
- **WHEN** 用户点击标题栏设置按钮
- **THEN** 弹出设置弹窗，默认选中"通用"分类

#### Scenario: 分类切换
- **WHEN** 用户点击左侧分类栏某一分类
- **THEN** 右侧面板切换显示该分类下的设置项

### Requirement: 设置项本地存储
设置项值（switch/seg/select/number）SHALL 保存到 localStorage 并在重启后保留；此版本设置值不驱动实际功能行为。

#### Scenario: 修改并保存设置
- **WHEN** 用户修改某设置项并点击"保存"
- **THEN** 该设置值写入 localStorage，弹窗关闭

#### Scenario: 取消修改
- **WHEN** 用户点击"取消"
- **THEN** 弹窗关闭，设置值回滚到打开弹窗前状态

#### Scenario: 恢复默认
- **WHEN** 用户点击"恢复默认"
- **THEN** 界面上的设置项全部恢复为默认值（未保存前不写入存储）

#### Scenario: 依赖项禁用
- **WHEN** 某设置项的依赖开关处于关闭状态
- **THEN** 该设置项呈禁用态且不可编辑
