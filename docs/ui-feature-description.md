# NetAssist — UI 界面与功能描述文档

> 本文档基于当前 `develop` 分支实现整理，用于后续 openDesign 深度设计时的功能与界面基线参考。
> 最后更新：2026-08-20

---

## 1. 项目概述

**NetAssist** 是一款基于 Electron 的跨平台 TCP/UDP 网络调试工具，主要用于嵌入式开发、物联网调试、网络协议测试场景。支持 TCP Client、TCP Server、UDP 三种通信模式，提供多标签页管理、多编码收发、HEX 查看、快捷发送、发送历史、统计等功能。

### 1.1 技术栈

| 层级 | 技术 |
|------|------|
| 桌面框架 | Electron 28 |
| 前端框架 | React 18 + TypeScript 5 |
| UI 组件库 | Ant Design 5 + @ant-design/icons |
| 状态管理 | Zustand 4 |
| 构建 | electron-vite + Vite 5 |
| 编码转换 | iconv-lite（GBK） |
| 持久化 | electron-store |
| 测试 | Vitest + Testing Library |

### 1.2 进程架构

```
┌─────────────────────────────────────────────────────┐
│  Main 进程 (Node.js)                                 │
│  ├─ ConnectionManager（TCP/UDP 连接生命周期管理）      │
│  ├─ gbk-codec（GBK 编解码）                           │
│  ├─ ipc-router（IPC 通道注册）                        │
│  └─ tab-store（标签持久化，electron-store）           │
└──────────────┬──────────────────────────────────────┘
               │ IPC (contextBridge 暴露 window.electronAPI)
┌──────────────▼──────────────────────────────────────┐
│  Renderer 进程 (React)                              │
│  ├─ MainLayout（主布局：侧边栏 + 内容区）             │
│  ├─ TabBar（连接列表）                               │
│  ├─ QuickSendPanel（快捷发送）                       │
│  ├─ TabContent（配置 + 消息 + 发送）                 │
│  └─ Zustand tab-store（全局状态）                    │
└─────────────────────────────────────────────────────┘
```

## 3. 连接列表（TabBar）

位于左侧边栏顶部，展示所有连接标签。

### 3.1 顶部栏

- 标题「连接列表」
- 右侧 **「+」下拉按钮**：点击弹出菜单，选择新建类型 —— **TCP Client / TCP Server / UDP**

### 3.2 标签项（每项一行）

| 元素 | 说明 |
|------|------|
| 状态圆点 | 按状态着色：`idle` 灰 / `connecting` 黄 / `connected` 绿 / `listening` 绿 / `error` 红 |
| 类型标签 | 彩色小标签：TC（绿）/ TS（蓝）/ UD（橙） |
| 标题 | 默认 `TCP Client 1`、`TCP Server 1`、`UDP 1`（按序号递增），双击可重命名（inline Input） |
| 关闭按钮 | 悬停显示，点击关闭标签并断开连接 |

### 3.3 交互行为

- **单击**：切换激活标签
- **双击标题**：重命名
- **拖拽**：支持拖拽调整标签顺序（原生 HTML5 DnD），目标位置虚线高亮，拖拽后抑制 click 误触；顺序通过 `persistTabs` 持久化，重启保留
- 最大标签数：**20 个**（超过时新建返回 null）

---

## 4. 快捷发送（QuickSendPanel）

位于连接列表下方，管理常用发送指令。

### 4.1 顶部栏

- 标题「快捷发送」
- **新建分组** 按钮（📁+）
- **新增指令** 按钮（+）

### 4.2 树形结构

- **分组**：可重命名、删除（删除时组内指令变为未分组）
- **未分组**：默认分组容器
- **指令项**：名称 + 内容，悬停显示操作按钮：
  - **发送**（▶）：将内容发送到当前激活标签（遵循该标签的编码与 LF→CR 设置）
  - **编辑**（✎）：修改名称/内容/分组
  - **删除**（🗑）：带 Popconfirm 确认

### 4.3 交互

- **拖拽指令**：可拖入其他分组（含未分组）调整归属
- **分组拖拽**：分组不可作为拖放目标（仅指令可拖入分组）
- 全部数据通过 IPC 持久化（`qs:load` / `qs:save`），重启保留

### 4.4 对话框

- **新增/编辑指令**：Modal，字段 = 指令名称 + 指令内容（TextArea）
- **新建/重命名分组**：Modal，字段 = 分组名称
- 名称/内容为空时确认按钮禁用

## 5. 主内容区（TabContent）

无激活标签时显示占位提示「点击左侧 "+" 按钮新建连接」。

### 5.1 配置面板（按标签类型区分）

#### 5.1.1 TCP Client

| 控件 | 说明 |
|------|------|
| 主机 Input | 默认 `127.0.0.1`，已连接时禁用 |
| 端口 InputNumber | 1-65535，已连接时禁用 |
| 连接/断开按钮 | 未连接显示「连接」（primary）；已连接/连接中显示「断开」（danger） |
| 状态 Tag | `未连接` / `连接中...` / `已连接` / `错误` |

#### 5.1.2 TCP Server

| 控件 | 说明 |
|------|------|
| 监听端口 InputNumber | 1-65535，监听中禁用 |
| 开始监听/停止监听按钮 | primary / danger |
| 状态 Tag | `未启动` / `监听中` / `错误` |
| 发送目标 Select | 监听中且有客户端时显示：「广播所有客户端」或具体客户端 `IP:端口`，用于单播/广播切换 |

监听中通过 `onClientJoined` / `onClientLeft` 实时维护客户端列表。

#### 5.1.3 UDP

| 控件 | 说明 |
|------|------|
| 本地端口 InputNumber | 1-65535 |
| 目标主机 Input | 默认 `127.0.0.1` |
| 目标端口 InputNumber | 1-65535 |
| 绑定/关闭按钮 | 绑定（primary）/ 关闭（danger） |
| 状态 Tag | `未绑定` / `已绑定` / `错误` |

### 5.2 消息显示区

#### 5.2.1 视图模式

- **合并视图**（`splitView=false`）：单一消息列表，显示 TX+RX 全部消息；右上角有「清空」按钮（danger，无消息时禁用）
- **分屏视图**（`splitView=true`）：左右两个面板，左侧「TX 发送」，右侧「RX 接收」；每个面板有独立「清空」按钮；中间分割条可拖拽调整比例（25%-75%）

分屏比例、合并/分开状态均通过 `sendOptions.splitView` 持久化。

#### 5.2.2 消息项（MessageItem）

每条消息显示为：

```
[08:55:52.629]→127.0.0.1:2001(438 bytes)
    消息具体内容
```

| 元素 | 说明 |
|------|------|
| 时间戳 | `[HH:MM:SS.mmm]` |
| 方向符号 | TX：`→`（绿色）/ RX：`←`（蓝色） |
| 远端地址 | 如 `127.0.0.1:2001`（橙色） |
| 字节数 | `(438 bytes)`（灰色） |
| 内容 | 换行缩进 12px 显示；文本模式 / HEX 模式 |
| 复制按钮 | 悬停显示，点击复制原文，成功显示对勾 1 秒 |

- TX 消息底色浅绿 + 左边框绿色；RX 消息底色浅蓝 + 左边框蓝色
- 文本模式支持 **ASCII 控制字符高亮**：`<CR>` `<LF>` `<TAB>` 等以彩色标签渲染并换行
- HEX 模式：字节以大写十六进制 `AA BB CC` 空格分隔
- **双击面板清空**：双击消息区清空对应面板消息（分屏模式下双击 TX 面板仅清空 TX，双击 RX 面板仅清空 RX；合并模式下清空全部）
- 自动滚动到底部；单标签消息上限 5000 条（超出移除最旧）

#### 5.2.3 编码

| 编码 | 发送编码 | 显示解码 |
|------|---------|---------|
| UTF-8 | TextEncoder | TextDecoder('utf-8') |
| ASCII | 每字符 & 0x7F | String.fromCharCode |
| GBK | iconv-lite encode | iconv-lite decode（渲染进程显示 GBK 文本经主进程预解码） |

> 注：`StatsBar` 组件（TX/RX 字节数、速率、时长）已实现但当前未挂载到界面。

### 5.3 发送面板（SendPanel）

#### 5.3.1 工具栏

| 控件 | 说明 |
|------|------|
| 编码选择器 | Radio.Button 组：`ASCII / UTF-8 / GBK`，默认 UTF-8 |
| TXT/HEX 切换 | 按钮切换显示/发送模式（文本 ↔ 十六进制） |
| LF→CR 开关 | 发送时将 `\n` 转换为 `\r`；**新建连接默认关闭** |
| 发送历史下拉 | Select，列出已发送历史（去重，最新在前），选择后填入输入框；无历史时禁用 |
| 合并/分开按钮 | 分屏模式切换（仅分屏相关），图标 + 文字 |

#### 5.3.2 快捷指令标签

当存在快捷发送指令时，输入框上方显示一排标签（`.send-quick-tag`），点击将指令内容填入输入框。

#### 5.3.3 输入框

- Ant Design `TextArea`，6 行，不可调整大小
- 未连接时禁用，placeholder：「请先建立连接」
- 已连接时 placeholder：「输入要发送的内容 (Ctrl+Enter 发送, Ctrl+↑↓ 历史)」

#### 5.3.4 操作按钮

| 控件 | 说明 |
|------|------|
| 发送按钮 | primary，未连接或无内容时禁用 |
| 清空按钮 | 清空输入框 |
| 提示文字 | 右侧显示 ASCII 控制字符统计（如 `ASCII: CR, LF`）或「Ctrl+Enter 发送」 |

#### 5.3.5 交互与快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Enter` / `Meta+Enter` | 发送 |
| `Ctrl+↑` / `Ctrl+↓` | 在发送历史中切换（↑ 回溯历史，↓ 前进；在最早处恢复草稿） |
| `↑` / `↓` | 正常移动光标（不触发历史切换） |

#### 5.3.6 粘贴行为

**拦截 `onPaste`**：从 `clipboardData.getData('text')` 读取剪贴板原始文本，`preventDefault()` 阻止浏览器将 `\r\n`/`\r` 规范化为 `\n`，按光标位置原样插入并恢复光标。保证用户复制什么就粘贴什么。

#### 5.3.7 发送历史

- 每次发送成功后，将发送内容插入历史（**去重**：相同内容移到最前，不新增）
- 发送后清空输入框
- 历史仅存于组件内存（不持久化）

## 6. 数据持久化

| 数据 | 存储方式 | 触发时机 |
|------|---------|---------|
| 标签列表 | electron-store（`store:load-tabs` / `store:save-tabs`） | 新建/关闭/重命名/改配置/改发送选项/拖拽排序时 |
| 快捷发送指令与分组 | electron-store（`qs:load` / `qs:save`） | 增删改指令/分组时 |
| 发送历史 | 仅内存 | 不持久化 |
| 消息记录 | 仅内存 | 不持久化 |

标签持久化字段：`id`、`title`、`type`、`config`、`sendOptions`（不含消息内容与状态）。

## 7. 连接与 IPC

### 7.1 IPC 通道

**Renderer → Main（invoke）**：
- `conn:connect` / `conn:disconnect` / `conn:send` / `conn:server-set-target`
- `store:load-tabs` / `encode:text` / `qs:load`

**Renderer → Main（send）**：
- `store:save-tabs` / `qs:save`

**Main → Renderer（事件）**：
- `conn:status` / `conn:data` / `conn:error` / `conn:client-joined` / `conn:client-left`

### 7.2 连接能力

| 类型 | 能力 |
|------|------|
| TCP Client | 连接/断开、发送、接收 |
| TCP Server | 监听、多客户端接入（实时列表）、单播/广播发送、客户端上下线事件 |
| UDP | 本地绑定、目标定向收发 |

### 7.3 安全配置

- `contextIsolation: true`、`nodeIntegration: false`、`sandbox: false`
- 外部链接通过 `shell.openExternal` 打开
- 应用菜单已移除

## 8. 已知行为约束

1. 消息上限：单标签 5000 条
2. 标签上限：20 个
3. 发送历史：仅内存，不持久化，去重
4. 新建连接 LF→CR 默认关闭（已有连接配置不受影响）
5. 粘贴保留原始换行格式（CR 不被规范化）
6. 分屏视图下 TX/RX 面板独立清空

## 9. 待设计/优化方向（供 openDesign 参考）

> 以下为基于现有实现与历史变更梳理的候选优化点，非当前需求清单，仅供设计参考。

1. **StatsBar 挂载**：`StatsBar` 组件（TX/RX 字节、速率、时长）已实现未使用，可设计接入点
2. **发送历史持久化**：当前仅内存，可评估跨会话保留
3. **GBK 渲染进程解码**：当前渲染进程 `decodeText` 对 GBK 返回占位符 `[GBK 解码不可用]`，依赖主进程预解码的 `text` 字段；可设计渲染进程直接 GBK 解码能力
4. **自动重连**：历史分支提及过 auto-reconnect 相关能力，当前未实现
5. **消息导出/日志**：无导出能力
